# Magi 0.1.0 beta

Magi lifts one Codex or Claude response into a large readable panel and adds a
Semi-Code Editor for desktop and terminal inputs.

This beta is distributed as source until the macOS app can be Developer-ID
signed and notarized. Clone the tagged repository and follow the build steps in
README.md. Do not redistribute the locally generated `UNNOTARIZED` archives as
public binaries.

Highlights:

- Whole-response Option-click reading for Codex and Claude desktop.
- Direct desktop input editing and guarded terminal replacement without Return.
- Privacy-safe manual diagnostics and transient clipboard restoration.
- Permission-free Rust reader with explicit Paste now, opt-in Auto-update, and Clear.
